# OTTPlay LG 0.4.12 candidate

Keep current programme titles, progress bars and the selected programme description visible while the channel-list guide refreshes in the background. A programme transition on one channel no longer hides the guide for every other channel. Each row still stops displaying a programme when its own interval ends.

Retain an admitted selected-channel guide during a same-source refresh, including a temporary refresh failure. Successful empty replies and actual channel, source or catalogue ownership changes continue to retire incompatible facts; stale worker replies remain rejected.

Install over the existing native application without changing profiles or channel selection. This candidate requires device validation; host tests and an ARM build do not establish physical display acceptance.

Verify downloaded package checksums with `sha256sum -c ottplay-lg-0.4.12.sha256`.

Package SHA-256: `__IPK_SHA256__`.
