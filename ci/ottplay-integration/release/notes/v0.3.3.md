# OTTPlay LG 0.3.3

Channel rocker input is available to the remote-control interface and recognizes the SDL PageUp/PageDown scancodes used by webOS input paths. Channel-list rows show the channel name and the configured number, its logo or a channel icon, EPG and archive availability, and the current programme when the guide has it. The completed catalogue no longer repeats the loaded-channel count. Existing channel-number display preferences remain in effect.

Install this package over the existing OTTPlay app. The stable app ID is unchanged, so profiles, Favorites and pairing state stay in the app's existing storage.

Package SHA-256: `__IPK_SHA256__`. Verify the downloaded package with `sha256sum -c ottplay-lg-0.3.3.sha256`.
