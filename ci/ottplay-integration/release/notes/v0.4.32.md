# OTTPlay LG 0.4.32 candidate

Native live HLS preserves a positively observed transport deadline through the
media-read callback and terminal failure report. The existing recovery policy
can then reopen the same channel instead of leaving a stopped decoder behind.
Successful operations and recovered seeks clear the observation; an old source
cannot attach it to a replacement session. Unknown errors retain their existing
closed classification.

A plaintext HTTP peer closing before its declared Content-Length is also
attributed as an incomplete body. The evidence is scoped to that response and
does not classify malformed chunk framing, unknown read errors or explicit
shutdown as a recoverable network interruption.

An explicit stream restart can also reopen an admitted current live channel after
terminal decoder cleanup. It resolves that exact retained catalogue selection
through the ordinary playback policy again, rather than reusing a retired URL.
Changed providers, media bindings, viewer intent and protected settings cannot
borrow the previous selection's authority. Existing active-stream restart keeps
its normal position and pause handling.

A remote numeric play command now addresses the configured channel catalogue
while a temporary Plex or Local queue is playing. For example, after a one-shot
Plex library command, `ott <player> 1` selects configured channel 1 rather than
queue item 1. Numbers use the ordinary catalogue across categories; the saved
provider and category are not overwritten. Physical remote digits, queue steps
and receipt-based catalogue commands retain their existing scope.

The receiver retains one bounded, complete catalogue at the first successful
temporary handoff. Missing, oversized or changed catalogues are rejected without
substituting a queue item. Protected targets still require ordinary playback
admission. See `docs/remote-channel-selection.md` for scope and recovery.

The application ID remains com.openottplay.player.native. Install over the
existing OTTPlay application to retain its storage identity. Hosted tests and
package verification do not prove uninterrupted physical-TV playback; sustained
device acceptance remains a separate result. No fixed preparation timeout is
reduced by this candidate.

Package SHA-256: `__IPK_SHA256__`.
Verify with `shasum -a 256 -c ottplay-lg-0.4.32.sha256` before installation.
