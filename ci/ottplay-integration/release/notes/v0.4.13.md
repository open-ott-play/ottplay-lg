# OTTPlay LG 0.4.13 candidate

Show the channel name without its catalogue number while the central startup or buffering spinner is visible. This applies to Classic and Modern. Normal playback information, channel-list numbering and deliberate numeric channel entry retain their existing identities.

The spinner is rendered by the application and can be redesigned independently of the webOS decoder. This candidate changes the startup label only; stream acquisition, codec inspection and buffering policy are unchanged. See docs/native-playback-startup.md for the startup path and the investigation procedure.

Install over the existing native application, preserving profiles and registration. Verify downloaded package checksums with `sha256sum -c ottplay-lg-0.4.13.sha256`.

Package SHA-256: `__IPK_SHA256__`.
