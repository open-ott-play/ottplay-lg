# OTTPlay LG development candidate

This repository contains native SDL2/OpenGL ES sources for LG webOS, including
Classic and Modern presentations. The package version remains 0.3.0 during
repository extraction; this document does not announce a published release.

Local builds produce a candidate package. If a matching candidate and checksum
file have been supplied, check them together:

```sh
sha256sum -c ottplay-lg-0.3.0.sha256
```

Source preparation and host checks do not establish television compatibility.
Protected settings persistence, playback and interface acceptance must be
recorded against the exact package before a release is qualified. The separate
audit records the currently unverified stages.
