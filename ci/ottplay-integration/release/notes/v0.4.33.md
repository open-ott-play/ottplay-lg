# OTTPlay LG 0.4.33

In Classic and Modern, the local editor shows source addresses, paths and
playlist links while you type or correct them. Passwords, PINs and access
keys still have masked editors.

A temporary service error while opening a live HLS fragment can now be retried
within the same playback session and request deadline. This lets playback use
the buffered data while the server recovers. A dropped connection on a direct
live HTTP stream also qualifies for the existing same-channel recovery policy.

For live streams with separate audio, a playlist refresh shares the current
connection and acquisition deadline. When an established live stream still
reports playing after both its position and position callbacks stop advancing
for ten seconds, the player can reopen the selected channel.

Package SHA-256: `__IPK_SHA256__`.
Verify the downloaded package with `shasum -a 256 -c ottplay-lg-0.4.33.sha256`.
