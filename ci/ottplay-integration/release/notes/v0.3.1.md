# OTTPlay LG 0.3.1

Fullscreen channel switching now handles LG channel-rocker scancodes and SDL PageUp/PageDown. A failed live channel stays selected with its error visible. HLS audio and video keep their original timestamp offset. Returning from the channel list preserves the selected item and scroll position, and the Modern footer keeps its navigation focus and status cues distinct.

Install this package over the existing OTTPlay app. The stable app ID is unchanged, so your profiles, Favorites and pairing state stay in the app's existing storage. Verify the downloaded package with `sha256sum -c ottplay-lg-0.3.1.sha256`.
