# OTTPlay LG 0.4.26 candidate

Configured OTT startup holds a neutral loading surface while the saved source,
catalogue and last-played request are restored. Menu and Channel list remain
available after cancellation, setup requirements or a real failure; they no
longer flash beneath automatic restoration. An authenticated native Home is
covered only while the existing saved-source navigation owner can proceed;
authentication, consent, setup and recovery screens remain usable.

Loading uses the shared four-colour orbit indicator without a central channel
name or ordinal. The destination footer shows the exact source title, known
channel number, artwork and available guide facts while the stream opens,
including targets outside the visible category or progressive row window.
Outgoing technical measurements are not reused for the destination. Pending
replacement keeps the footer visible unless explicitly dismissed or prohibited
by the active surface policy. Ordinary autohide returns when loading settles.

Text editors now show a field outline and an explicit keyboard/edit hint.
Hidden values are labelled as hidden; placeholders and masking never replace
the submitted value. Classic and Modern use the same underlying editor state.

Package SHA-256: `__IPK_SHA256__`.

Verify downloaded release files with
`shasum -a 256 -c ottplay-lg-0.4.26.sha256` before installation.
