# OTTPlay LG 0.4.11

The native Plex queue and library commands can use an already authenticated native account without requiring a second imported configuration. Imported credentials retain their exact source checks. Live transport recovery uses a bounded same-channel policy for positively classified temporary failures; unsafe, unauthorized and unclassified failures do not trigger retries. Legacy Favorites retain their previous exact profile binding, while ambiguous sources remain rejected.

Classic lists move directly by complete rows without intermediate spring frames. Selecting a channel or video immediately shows the standard loading overlay; Back cancels pending selection and restores the same list position. Play/Pause opens Category selection from Classic channel and Favorites lists. Failed explicit selections keep their selected item, while normal end-of-file advancement remains available.

Magic Remote scrolling preserves every wheel notch without the former 250 ms debounce, with a bounded eight-row limit per event. Notifications have a thin blue perimeter on all four sides; warning and critical notifications retain their corresponding colors. The border fades with the banner surface, and text keeps its existing readability.

Explicit provider IDs and indices now take precedence over partial provider labels. Selecting Plex remotely can rebuild missing profiles from existing credential-eligible native servers in one acknowledged save, using the same metadata planner as the interface. Native tokens, account scope and authorization remain unchanged; exact preset credential comparisons do not treat this metadata recovery as a token match.

Remote control settings expose the confirmed installation Device ID as read-only for first-time registration. Provisional or unavailable identities are not offered for registration. The same public identifier is recorded once after confirmed configuration load; no control credentials or endpoints are logged.

Muxed HLS audio and video share one continuous transport timestamp mapping across segments. Rounded playlist durations no longer independently shift the two media lanes. Decoder continuity and seek/discontinuity guards remain in place.

Live-channel failures retain the selected source. Playback errors use a compact nonmodal notice. Classic channel rows show inline programme, bounded artwork, archive indication and progress; the playback footer retains the admitted channel header and actual decoder dimensions. External H.264 playback recognizes strictly validated immediate recovery points.

An explicitly configured hosted EPG service can supply M3U programme data when the playlist declares no XMLTV guide. The setting uses the existing string settings protocol and does not copy CLI search-service configuration automatically.

The installed firmware channel-rocker codes 480/481 are accepted alongside the original 300/301. A bounded read-only input probe is available during an authenticated playback diagnostic capture. HLS HEVC/AC-3 playback keeps the selected transport PID and requires matching native decoder capabilities.

After a failed explicit channel step, the next CH+/CH− action advances relative to that attempted channel, without automatic switching. The central button can reopen the source-bound catalogue after playback cleanup. Playback error notices contain text only, with no Back/Retry row or focus capture. HLS HEVC/AAC uses the existing validated video/audio transport and native capability checks. Read-only status counters distinguish accepted guide data from the published catalogue presentation.

Native provider profiles retain their real operator identity. The candidate adds Edem/iLook configuration and canonical operator TV catalogues, playback and programme-guide adapters, portable Favorites, and guarded remote credential updates. Edem uses the current fixed stream endpoint and preserves separate channel and guide identifiers.

Live HLS audio renditions and WebVTT subtitles use bounded refresh, actual media clocks and source/epoch-bound selection. Native subtitle policy supports Off, Auto and Forced with a language preference and manual-choice precedence. Provider archive playback and lazy Records browsing retain source and programme identity.

Install over the existing main application; the application ID is unchanged. This candidate is for validation. Additional embedded-caption and operator movie-service work is tracked separately and must not be inferred from provider registration. Device acceptance is recorded against the exact package hash.
