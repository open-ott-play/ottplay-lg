# OTTPlay LG 0.4.25 candidate

After an accepted fullscreen Next/Previous command, reopening Channel list now
selects the requested channel or video instead of an older browse highlight.
The same source-bound selection policy covers channel rockers, reverse steps
while a destination loads, Favorites and native Plex list stepping.

Browse selection remains independent while the list is open. Refused input and
stale resolver completions do not gain permission to change that selection.
Profile, category and temporary-source boundaries remain unchanged.

The established single-view playback path remains the default. Native multiview
is still explicitly configured and experimental, without physical-TV qualification.

Package SHA-256: `__IPK_SHA256__`.

Verify downloaded release files with
`shasum -a 256 -c ottplay-lg-0.4.25.sha256` before installation.
