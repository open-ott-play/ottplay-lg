# OTTPlay LG 0.3.2

Channel rocker input is available to the remote-control interface and recognizes the SDL PageUp/PageDown scancodes used by webOS input paths. Channel-list rows keep the channel name and number visible, show its logo or a channel icon, mark EPG and archive availability, and show the current programme when the guide has it. The completed catalogue no longer repeats the loaded-channel count.

Install this package over the existing OTTPlay app. The stable app ID is unchanged, so profiles, Favorites and pairing state stay in the app's existing storage.

Verify the downloaded package with `sha256sum -c ottplay-lg-0.3.2.sha256`.
