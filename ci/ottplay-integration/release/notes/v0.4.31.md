# OTTPlay LG 0.4.31 candidate

Modern uses native collection cards for providers, profiles and categories.
Management and disabled controls remain reachable without forcing playable
content into a text form. Container actions retain their canonical navigation,
while playback, preview and Favorites remain restricted to actual media items.
Source-bound focus and Description returns reuse the current application state.

A bounded All shelf keeps uncategorized content alongside real provider category
shelves. Current category membership supplies counts and representative artwork.
Explicit M3U live metadata selects landscape channel cards; channel and container
images fit without cropping. VPortal prefers its portrait poster with existing
validated fallbacks. Already discovered ordinary Local covers can remain visible
through focus changes using a 64-entry, 256 KiB proof cache with current-root checks.
No media copies, new scan or new source permissions are introduced.

Classic contextual Left opens Categories for both finite media and live channels.
Back in every typed OSD picker returns to Settings even when it covers a video
panel, retaining drafts, catalogue work and the caller's navigation owner.

Opt-in command-activity v2 correlation is available with a matching controller
and CLI. Existing status activity v1 remains unchanged. A response or correlation
ID does not identify a human or prove playback execution.

The stable application ID, profiles and permissions remain unchanged. Hosted
checks and package verification do not establish physical-TV acceptance. This
candidate does not imply an update to any currently playing device.

Package SHA-256: `__IPK_SHA256__`.
Verify with `shasum -a 256 -c ottplay-lg-0.4.31.sha256` before installation.
