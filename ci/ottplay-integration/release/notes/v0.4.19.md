# OTTPlay LG 0.4.19 candidate

Add Providers → System television / LG Channels in Classic and Modern. Read the paired television's channel catalogue and transfer a selected channel to LG's system player after releasing OTTPlay's decoder. The current OTT profile remains configured.

System television requires an updated controller, an explicitly enabled player channel binding and renewed TV pairing for channel permissions. Available LG Channels depend on the television and region. The system player owns viewing after handoff; this does not provide OTTPlay's HUD or strict kiosk over system video.

Malformed and stale catalogues are rejected. A channel change is submitted once, and an accepted request is distinguished from an observed matching channel. Pending handoff is cancelled when its screen, connection or playback authority changes.

A separate experimental transparent web-overlay probe is included in source for deliberate hardware validation. It is not bundled into or automatically launched by the player. No physical-TV acceptance or public stable qualification is claimed for this candidate.

Package SHA-256: `__IPK_SHA256__`.

After downloading the release assets into one directory, verify them with `shasum -a 256 -c ottplay-lg-0.4.19.sha256` before installation.
