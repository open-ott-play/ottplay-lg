Local candidate installed and launched over the main application on the living-room LG. Remote status confirmed version 0.4.11 and build 3a7f539. These observations remain host fixture/shutdown timing limits, not proof of a particular production cause.

## Compatibility tiers, and what moved

No firmware tier changes are asserted. Native-account command preparation uses existing account authorization and an exact active or unique profile; ambiguous, unavailable or revoked sources remain rejected. Explicit imported credentials retain their original source checks.

## Known issues at release, with provenance

Unclassified plaintext transport errors and playlist-fetch errors remain conservative and do not gain automatic retries. Authentication, TLS trust, unsafe requests and unsupported sources are not treated as temporary network failures. The new retry policy does not prove that every previously observed stream failure is repaired. Physical acceptance remains deferred; exact candidate test and runtime results are recorded above.

## Release configuration

Application ID remains `com.openottplay.player.native`; package version is `0.4.11`. Main-ID packaging uses `FLAVOR=stable RELEASE=1` to preserve application storage; this naming does not itself qualify a public stable release.
