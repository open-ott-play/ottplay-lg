## Compatibility tiers, and what moved

The local backend is the default. Each window owns bounded decoding, source
permission, cancellation and provider cleanup. It supports PiP, grid4, grid9
and a large central window with up to eight satellites. GLES renders planar
frames directly. Remote focus and pointer selection share the same geometry;
one acknowledged audio owner feeds SDL at the player's desired volume/mute.

M3U, VPortal, Plex and held local files retain their original provider/profile
bindings. Replacement and restoration wait for decoder and lease retirement.
Fresh parental, kiosk and source authorization remain mandatory. Strict kiosk
refuses multiview. Background retirement does not restart the previous source.
The existing closed command protocol and protected service binding are retained.

Real decoder tests exercise paused non-keyframe seeks, pause toggles, stale
epochs, HLS seek refusal, revocation and unpaused audio within one actual PCM
chunk of the video landing. Virtual framebuffer comparisons, gain/mute captures
and owned-process cleanup passed independently. These are functional host
results, not television throughput or audible hardware results.

## Release configuration

Numeric version 0.4.27 retains com.openottplay.player.native and the OTTPlay title
for in-place updates. Version preparation changes only the four numeric package
manifests, product metadata and this version's authored notes/audit. No profiles,
credentials, application ID, permissions or production code change in this PR.

The existing main-only beta pipeline must freeze the exact source/version plan,
run required checks, build the production ARM package with bundled software
decoders, verify ELF/link/package provenance, and compare published bytes with
the original candidate. A beta is not a stable qualification record.

## Known issues at release, with provenance

Physical SDL backend availability, speakers, rendering, sustained decoder count
and thermal behavior remain unqualified. Limits are admission safeguards:
1080p input pixels, 8-bit planar YUV420 and 15 fps presentation per window do not
promise nine HD streams. The source snapshot is bounded to 1152 captured rows.

The initial local HLS reader rejects encrypted, byte-range, discontinuous and
external-audio renditions and does not seek HLS. Progressive HTTP seek depends
on the final response declaring byte-range support; each actual seek still
validates its response. Untimed packets after seeking are not presented as
post-target audio. Plex uses direct media without starting a transcoder.
