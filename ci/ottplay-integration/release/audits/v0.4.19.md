# OTTPlay LG 0.4.19 candidate audit

## Device test evidence

No physical television was paired, tuned, installed or launched for this feature. Host checks and local ARM packaging are distinct from hardware acceptance. The system-TV path remains subject to explicit consent and validation on each target TV.

## External compatibility reports known at release time

LG ConnectSDK implements channel catalogue, current-channel, current-programme and exact tuning operations. An independent regional LG Channels controller uses explicit channel-number selection. Those sources establish an implementation path, not compatibility results for this package on our TVs.

## Compatibility tiers, and what moved

No physical-TV compatibility tier changed. Classic and Modern share the new system-TV page. Actual channel and programme availability depend on the paired television, signal configuration and region.

## Known issues at release, with provenance

The system player owns video and remote input after handoff. OTTPlay's HUD, strict kiosk, complete EPG, archive and direct tuner/FAST stream decoding are not implemented by this path. LG Channels not enumerated by a TV are not invented in its catalogue. A transparent web-overlay probe is a separate experimental app and has not been tested on hardware.

## Deliberately not done

No TV or production-controller deployment, automatic pairing, hidden privilege escalation, system-app input interception or changes to existing profiles were performed. Existing paired keys must explicitly gain channel permissions through renewed consent. This candidate has not been promoted to a public stable release.

## Release configuration

Version 0.4.19 retains the primary application ID and uses FLAVOR=stable RELEASE=1 with the standalone OTT product configuration. Device credentials and administrator tokens remain outside the package. The native player uses its own paired token with an opt-in device-bound channel endpoint. A channel-only alias can resolve that token to an existing canonical TV binding without replacing the older player or creating a second TV command queue. Local checks passed for the native runtime, the new handoff cases, localization and controller/CLI behavior; these are not physical playback acceptance.
