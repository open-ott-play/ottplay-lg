# OTTPlay LG 0.4.20 candidate audit

## Device test evidence

On the installed 0.4.19 candidate, a user reported a frozen first-channel picture. A thirty-second capture showed a stopped playback position at approximately 240 seconds, no transport error, HTTP 200, retained playable media and a full video queue. Feed and callback counters did not advance. These observations identify a stalled pipeline but do not independently prove decoded-frame presentation.

Code review found that external HLS entered the native rebuffer clock protocol without publishing interval completion evidence. New regression tests exercise the actual external feeder against bounded queues and a simulated native actuator, covering both a hold before feeding and a producer parked before the hold. Those tests do not establish physical display acceptance of the new package.

The updated controller was deployed separately, retaining the canonical television binding and registry. Explicit pairing consent was confirmed by the user and the television returned 89 scanned terrestrial channels. No system-TV playback handoff or overlay display acceptance is claimed by that catalogue read.

## External compatibility reports known at release time

The user reports that the same freezing symptom is generally absent in the browser and Tauri players. Those clients use a different playback pipeline and do not execute the native access-unit rebuffer ownership protocol. This is not a claim that browser playback cannot stall for other reasons.

## Compatibility tiers, and what moved

No physical-TV compatibility tier changed. The patch applies to external multiplexed HLS and joined audio/video live and finite HLS producers. Network acquisition, bounded queue admission and decoder readiness remain separate facts.

## Known issues at release, with provenance

Long-running playback of this exact candidate still requires validation on the television. System television delegates playback to LG; direct tuner/FAST stream decoding, a complete guide, the native HUD over system TV and strict kiosk after system handoff are not established by this change. LG Channels availability depends on the television catalogue and region.

## Deliberately not done

No queue limit or buffer profile was enlarged to mask the stall. A user pause is not overridden. Invalid, stale, aborted or seek-superseded interval evidence cannot authorize automatic Play. The experimental transparent overlay remains separate from the installed player.

## Release configuration

Version 0.4.20 retains the primary application ID with FLAVOR=stable RELEASE=1 and the standalone OTT product configuration. The new package is prepared on an isolated Linux ARM builder. Source, host-simulation tests, ARM package checks and physical acceptance are separate evidence tiers. It is not a public stable promotion.
