# OTTPlay LG 0.4.33 candidate audit

## Device test evidence

The preceding 0.4.32 player reported repeated transitions from playing to
error on the same live channel. Controller history records the transitions.
The underlying HTTP response or decoder error for those transitions is unknown.

## External compatibility reports known at release time

The user reported sustained playback of the same channels on the desktop
player. The native HLS regression uses a local HTTP server that temporarily
refuses a fragment and subsequently serves the same fragment.

## Compatibility tiers, and what moved

The shared Classic and Modern editor displays editable source addresses.
Typed failures while reading live media can recover on the current selection.
Device and codec compatibility tiers are unchanged.

## Known issues at release, with provenance

Long-running playback on a physical television requires receiver acceptance.
Native position callbacks measure progress of the player clock. They do not
count frames actually shown by the television.

## Release configuration

The package updates com.openottplay.player.native in place. The release
workflow builds the ARM package and records its source and checksums.
