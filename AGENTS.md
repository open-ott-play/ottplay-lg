# Repository work

Work in this primary checkout on ordinary Git branches. Coordinate file ownership
before concurrent edits; do not create linked worktrees unless requested.
Preserve local configuration and other contributors' uncommitted work.

Classic and Modern are presentations of one application state. Renderers do not
own provider credentials, catalogue identity, playback policy or persistence.
Reuse the pinned OttPlay shared core before adding another domain implementation.

Preserve GPL and dependency notices and source provenance. Never commit device
addresses, credentials, private logs or build outputs. Do not include assistant
or tool attribution in commit messages.

Run relevant checks. Host tests, simulators, ARM builds and physical-TV acceptance
are distinct results. Device installation and launches require task authorization.
Keep temporary material under ~/.codex/artifacts. Use Markdown or ordinary HTML
for reports, not Canvas.
