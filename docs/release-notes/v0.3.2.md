# OTTPlay LG v0.3.2

## Fixed

- Fullscreen channel-up/channel-down input is routed through the same next/previous channel action and is exposed through the authenticated OTT CLI input capabilities.
- Channel-list rows show their channel number and name, the available logo or a channel icon, EPG/archive availability, and the current programme when the profile provides it.
- The channel list no longer repeats a loaded-channel count after the catalogue has finished loading.

## Update

Install this package over the existing OTTPlay app to keep its profiles, Favorites and pairing state. Verify the downloaded package with `sha256sum -c ipk.sha256`.

Package SHA-256: `__IPK_SHA256__`
