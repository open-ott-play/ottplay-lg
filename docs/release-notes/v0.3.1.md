# OTTPlay LG v0.3.1

## Fixed

- Fullscreen CH+/CH− switching now recognizes both LG's native channel-rocker scancodes and SDL PageUp/PageDown symbols, routing them to the next or previous live item.
- A failed live channel remains selected with its error visible instead of silently switching to another channel.
- HLS audio and video retain their original timestamp offset, reducing A/V drift on streams whose tracks start at different timestamps.
- Returning from the channel list preserves its selected item and scroll position; Modern footer focus and status cues stay distinct.
- Authenticated remote playback diagnostics can capture bounded playback-health samples without enabling the on-screen diagnostics panel.

## Update

Install this package over the existing OTTPlay app to keep its profiles, Favorites and pairing state. Verify the downloaded package with `sha256sum -c ipk.sha256`.

Package SHA-256: `__IPK_SHA256__`
